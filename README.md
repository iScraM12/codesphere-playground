# codesphere-playground

This repository is split into two parts:

- [`backend/`](./backend) — a basic Quarkus application (latest version) with a sample REST
  endpoint and the MongoDB (Panache) extension pre-configured, ready to connect to a MongoDB
  instance. See [`backend/README.md`](./backend/README.md) for details on running, building and
  testing it.
- [`frontend/`](./frontend) — currently empty, reserved for the frontend application.
